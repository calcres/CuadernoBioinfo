Introducción

unque existen muy buenos programas para inferir filogenias fuera del entorno de R (es decir, para el terminal de Bash), utilizar las herramientas en R tiene la ventaja de poder representar los árboles, manipularlos y extraer información de ellos con toda la flexibilidad que permite un lenguaje de programación. Otros programas como RAxML o IQtree producirían los resultados en forma de archivos de texto con formato Newick o NEXUS. En R, los árboles serán objetos de clase phylo, que pueden también ser exportados como archivos de texto con formato Newick con la función write.tree() del paquete ape. Este paquete será cargado automáticamente cuando carguemos el paquete phangorn, que proporciona las principales funciones para inferencia filogenética.

Para qué sirven las funciones add.scale.bar() y axisPhylo()? add.scale.bar(): añade una barra horizontal dando la escala de la rama dentro de un árbol. El valor es calculado de los datos.

axisPhylo(): añade un eje a escala en un lado del árbol filogenético. Incluye los siguientes argumentos:

side
a numeric value specifying the side where the axis is plotted: 1: below, 2: left, 3: above, 4: right. By default, this is taken from the direction of the plot.

root.time
the time assigned to the root node of the tree. By default, this is taken from the root.time element of the tree. If it is absent, this is determined from the next option.

backward
a logical value; if TRUE, the most distant tip from the root is considered as the origin of the time scale; if FALSE, this is the root node

En este caso sirve como escala del tiempo que podemos elegir que cuente hacia atrás desde el momento actual (TRUE) o desde la raíz (FALSE).
